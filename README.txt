# ARCHI · CHANGE — 건축물 용도변경 판독 도우미

## 파일 구성
- `index.html` : 웹사이트 구조
- `style.css` : 디자인, 반응형 화면, 애니메이션
- `script.js` : 세부 용도 목록, 선택 기능, 기본 절차 안내
- `images/building-before.png` : 변경 전 패널용 건축물 이미지
- `images/building-after.png` : 변경 후 패널용 건축물 이미지

## PC에서 실행
1. ZIP 파일을 압축 해제합니다.
2. `ARCHI-CHANGE` 폴더를 엽니다.
3. `index.html`을 더블클릭합니다.

## GitHub Pages에 올리기
저장소에 `index.html`, `style.css`, `script.js`, `images` 폴더를 함께 업로드합니다. 파일과 폴더 이름을 바꾸지 마세요.

## 현재 구현된 기능
- 9개 시설군과 세부 용도 목록 표시
- 세부 용도 검색
- 변경 전(파란색)·변경 후(주황색) 용도 선택
- 선택 항목 강조와 화살표 클릭 애니메이션
- 선택한 시설군 번호를 바탕으로 한 기본 절차 안내
- 모바일 화면 대응

## 중요한 안내
이 버전은 화면과 기본 동작을 확인하기 위한 1차 시제품입니다. 세부 용도는 간단한 목록으로 구성했으며, 모든 건축물 용도 세부 항목과 시행령 별표 1의 예외 규정을 완전하게 반영하거나 법적 판정을 검증한 상태가 아닙니다. 실제 용도변경 여부는 현행 법령, 건축물 현황, 관계 법령 및 관할 허가권자 확인이 필요합니다. 결과를 확정적 법률 판단으로 사용하지 마세요.

## 참고 법령
- 건축법 제19조: https://www.law.go.kr/
- 건축법 시행령 제14조 및 별표 1: https://www.law.go.kr/


## 수정 사항 (오류 수정 버전)
- 오른쪽(변경 후) 화살표가 중앙 목록을 향하도록 왼쪽 방향으로 수정했습니다.
- 세부 용도를 선택하면 해당 시설군 번호에 따라 해당 화살표가 위아래로 이동합니다.


## 화살표 시설군 이동 기능 보강
- 파란색/주황색 화살표를 클릭할 때마다 다음 시설군으로 이동합니다.
- 중앙 목록의 해당 시설군 행이 파란색/주황색 테두리로 강조되고 목록이 해당 행으로 스크롤됩니다.
- 화살표를 우클릭하면 이전 시설군으로 이동합니다(일부 모바일 기기에서는 우클릭 기능을 사용할 수 없습니다).
- 이동한 시설군에서 세부 용도를 클릭하면 해당 용도가 변경 전/후 선택값으로 지정됩니다.
